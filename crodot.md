# DUI

DUI is not driving under influence, but in this case it means Davids UI. It is an odin library with UI and graphical utilities for use with **odin** and **raylib**. Please note that David is not a very capable programmer in general and definitely not when in comes to graphics and UI's.

Help David with creating this DUI library please. We are making **odin** procedures that can be used in other projects. For example:

- basic layouting options, like centering, dividing, etc.
- basic elements, like text areas etcetera.

Note that whilst we are writing in odin, many of the procedures we are calling, use raylib; thus we are often using odin c-types, like cstring and c.int.
